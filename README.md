Version 0.1.3 (test build)

INSTALL
unzip to game folder, only tested with virtual desktop XR,

VIEW
  * THIRD PERSON (default): you stand where the game's side-view camera is and see the world like a diorama, in 3D;
    the view follows the game camera. VR menu: move closer / further / up / sideways.
  * FIRST PERSON: you are the character - look around freely. The LEFT STICK WALKS WHERE YOU LOOK: push forward and
    he walks the way you face along the game's left / right path. Right stick up / down = up / down (climb, swim),
    right stick left / right = turn.
  * HOLD R3 (right stick click) 1.3 s = switch 1st / 3rd person (outside play: re-centre).
  * Menus / pause: the game's picture on a big screen in front of you. The HUD floats in front of you in play.

XBOX CONTROLLER (play with a normal gamepad - the mod's own controls work on it too)

  Hold R3 1.3 s ............ 1st / 3rd person (outside play: re-centre)
  
  L3 + R3 clicked .......... re-centre;
  
  L3 + R3 HELD 1 s = VR settings (stick / D-pad = choose / change, A, B = close)
  
  First person ............. left stick walks where you look, right stick left / right = turn, up / down = climb / swim

CONTROLS WITH VR CONTROLLERS (they act as an Xbox gamepad - the game's own gamepad controls)

  Left stick ........... move   
  
  Right stick ...... left / right = turn (up / down = the game's)
  

  Left stick click ..... L3 
  
  Hold R3 1.3 s .... 1st / 3rd person
  
  X + Y together ....... Start (pause)
  
  A + B together ... Back
  
  BOTH stick clicks .... click = re-centre;  HOLD 1 s = VR settings menu
                         (stick up / down = choose, left / right = change, A = switch, B = close)

Disable: to disable Mod rename winhttp.dll to winhttp.dll.bak
